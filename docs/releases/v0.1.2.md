# Recontrol Lang v0.1.2

This release focuses on predictable semantics, safer ownership, project workflow,
source diagnostics, modules, and the first enum/match implementation.

## Language

- true short-circuit evaluation for `&&` and `||`;
- fixed array length is part of the type;
- mutable references are move-only rather than freely copyable;
- decimal range checking for `i256` and `u256` literals beyond `u128`;
- deterministic integer division failure for zero divisors and signed MIN / -1;
- `pub` visibility and namespaced imports with `use "file.rcl" as name`;
- fieldless enums;
- exhaustive `match` with compile-time checking for missing, duplicate, and unknown variants.

## Compiler and diagnostics

- source IDs and precise spans across imported files;
- borrow diagnostics include the conflicting use and the borrow origin;
- HIR/MIR/LLVM lowering for fieldless enums and match control flow;
- native enum representation with no heap allocation;
- expanded MIR validation, move analysis, and borrow analysis.

## Tooling

- project entry support through `rcl.toml`;
- `rcl build`, `rcl run`, `rcl test`, and `rcl fmt`;
- prebuilt runtime shipped beside the compiler instead of invoking `rustc` for every build;
- Linux and Windows release packaging with checksums.

## Verification

The CI suite covers Rust unit tests plus native LLVM run-pass, run-fail, and
compile-fail programs, including short-circuiting, arrays, namespaces, wide
integer literals, imported diagnostics, borrow diagnostics, division failure,
and exhaustive enum matching.
